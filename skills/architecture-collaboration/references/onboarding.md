# 首次使用与项目配置向导

仅在新项目需要引导或用户主动要求重配时读取。目标是让使用者知道要准备什么、下一步做什么；不是先填完整表单才能设计。

## 入口判断

- 先看当前请求及项目现有黑板/启动记录；已选择模式、已有可用任务书或明确局部工作时沿用，不重复访谈。
- 真正的新项目用一次简短选择提供：**跟着做**（逐步引导）、**自定义流程**（选择环节）、**接续项目**（识别旧成果）。用户已经表达的选择优先。
- 初次缺少启动记录不代表用户没有经验；可跳过引导。没有跨会话可读状态时说明缺口，不能声称已记住。

## 跟着做：分批收资料

第一批只补当前启动所需，先复用已给内容：

| 输入 | 具体要什么 | 暂缺时怎么办 |
|---|---|---|
| 作业与场地 | 任务书、场地/周边、建筑类型、项目地区、交付内容、截止时间 | 明确未知项，先整理任务，不编面积或地形 |
| 目标与体验 | 想解决的问题、希望发生的活动、意象、教师意见 | 提出少量有依据的方向候选，帮助共同定义问题 |
| 参考偏好（可选） | 喜欢的建筑师、具体作品、图片及喜欢的原因 | 没偏好也能开始，不强制选大师 |

第二批按方案需要补，避免一口气索取全部资料：

- **研究**：围绕当前问题找思想/访谈、可靠研究、作品集与图纸。能联网时先核实书名、作者、版本、来源与相关性，再给必要下载清单及公开/合法获取入口；不能检索时标待核。已有书先用，不让用户重复下载。收到文件后按 learning.md 归档并记录实际核读范围；导入/OCR/索引不等于研读。用图文理解原作，参考偏好不自动成为设计主张。
- **规范**：按地区、用途、规模和适用时间建立待核清单，核实有效版本、条文范围与关键约束；优先可靠官方来源。让用户补充无法取得的文本，不把国外案例或未知版本当本地规范结论。影响布局成立的条件前置，不留到最后才查。
- **工具**：先问交付需要和实际已有软件，再检查当前会话可用的接口与版本；软件已安装不代表助手能控制。研究/方案讨论无需先安装全部建模软件。CAD、Revit、SU、渲染按需要配置，缺接口时说明可交付替代和未能验证项，不承诺自动导出所有原生格式。
- **补充**：预算、材料、运行、气候、生态、无障碍、模型/图纸等随相关决策补齐；保护私人资料，上传任务不等于允许公开原书或项目。

每轮只问当前最关键的少量问题；已知内容不再问。用户可先做研究、讨论或局部任务，不能因清单未齐而一律停止。

## 自定义与接续

自定义可选：资料研究、主张讨论、方案生成、总图/空间深化、规范与使用审查、建模绘图、表达出图；按依赖组合，不强制跑满。记录目标、输入、交付、复核与停止条件。

接续先识别主方案/其他方案、成果版本、现行总账与未闭合项；先读相关增量，不为接续重做研究和清单。多方案共用有效要求，各自记录证据。无法确定当前版时先澄清，不覆盖旧成果。

## 启动卡（写入现有项目黑板）

采用下列等价简表即可，无须新增数据库、重复配置文件或第二套完成状态：

```markdown
## 项目启动
- 模式：跟着做 / 自定义 / 接续（可改）
- 目标、阶段与交付：……
- 任务书/场地/当前成果入口与版本：……
- 方向：用户已确认……；候选……；不能混写
- 研究与个人库入口、实际已读范围：……
- 适用规范与待核条件：……
- 当前工具能力与交付限制：……
- 资料缺口：阻塞本步……；后续按需补……
- 首轮产物、验收总账入口与停止条件：……
- 下一步：……
```

启动卡给用户看，明确方向候选与资料缺口；明确授权内的可逆工作继续推进。确需用户决定的关键方向再问，不把未回复当同意，也不新增逐步审批。原始反馈与助手判断分开，原作方法与本案验证经验分开。

## 接下来怎么工作

按当前阶段衔接：研究证据 → 设计主张与候选 → 总图和空间 → 批评/复核 → 修改与交付。不是每轮都跑全部环节；遵守 SKILL.md 的投入分级及持续验收规则。引导不会自动启动多代理或八小时循环。平台映射真实记录，实际操作继续在对话中。

## 行为自检

- 新手只有任务书、没有喜欢的大师：能先整理目标，给可选参考，不逼其下载整库。
- 老项目只改一扇门：直接定位成果与关联要求，不展示三模式菜单。
- 用户只想研读盖里：停留在研读，不直接生成方案或声称已确认主张。
- 没有 Revit/SU 接口：如实说明交付能力，不假称已建模；其他工作继续。

# 新手快速上手：让助手带你开始

## 1. 安装技能

先把本体中的整个 `skills/architecture-collaboration/` 文件夹复制到你使用的助手技能目录，不要只复制 SKILL.md。以 Codex 为例，可放在用户目录的 `.codex/skills/architecture-collaboration/`；让助手重新发现技能，必要时重开会话。其他助手需按各自支持的技能/提示机制配置，不能保证通用自动识别。

在对话里调用 `architecture-collaboration`，或用客户端提供的技能选择器选择它。可以直接发：

> 用 architecture-collaboration 带我开始一份建筑作业，选择“跟着做”。我先提供任务书和场地，请列出眼下必要的资料，其他资料后面再补。

新项目按需给出三种模式：跟着做、自定义流程、接续项目。已有任务直接接续，想重配时说“重新打开项目引导”。技能是否被自动选中取决于客户端；不确定时明确调用。

## 2. 第一批准备什么

- **任务书与场地**：原文件、场地位置/周边、交付要求和截止时间。
- **想法**：期待什么空间与生活，当前困惑、教师意见；没有成熟主张也可以开始。
- **喜欢的参考（可选）**：建筑师、具体作品或图片，以及你喜欢哪里。没偏好可以一起找。

不用一开始搜齐全部规范、买齐书或装齐软件。助手先检查现有材料，按地区/用途列待核规范，再按研究问题给核实后的必要书目和来源；找不到的标待核。书籍、项目模型和个人积累留在外部资料目录，公开本体不含这些内容。

## 3. 你会先收到什么

一张“项目启动卡”：目标与交付、已有资料、缺口、方向候选、可用工具、首轮产物、验收依据和下一步。喜欢盖里不等于只能做扭曲外形；先解释参考思想如何转化成你这个项目的空间主张，再推敲总图、剖面和人视。

研究能以普通文件开始。需CAD、Revit、SketchUp或渲染时再配置对应软件和可用接口；仅安装本技能不会获得这些软件或接口。平台服务可选，安装方法与环境见 [README](../README.md) 和 [软件准备与工作流实例](WORKFLOW-EXAMPLE.md)。

## 4. 过程与接续

研究 → 主张 → 总图/空间 → 批评与复核 → 修改/交付；局部任务只走相关环节。持续验收要点保留，局部解决不代表永久通过，助手自评不代表老师或用户认可。你可随时说“先讨论，不实施”或指定当前环节。

下次在相同项目继续说“接续当前版，先看未解决项”即可；项目黑板和总账帮助恢复，跨新会话应提供项目目录或入口。平台展示落盘记录，操作仍在助手对话中，不会自己全天监控或无限循环。

## 5. 示例：以盖里研究为参考

带入任务书/场地及盖里资料 → 核读思想与作品图文 → 提出本案空间主张 → 用总图、剖面和人视检验 → 根据批评修改 → 形成方案表达与图纸。示例的成果依赖资料、操作者判断、工具和迭代条件，不是安装后的质量、费用或耗时保证。详细案例入口见工作流实例。
